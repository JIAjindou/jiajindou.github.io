{%- comment -%} Light / dark theme. Every new visit starts light; a switch to dark lasts for the browsing session only (sessionStorage: kept across reloads and the en/zh pages in that tab, gone in a new tab or window). Runs in before any stylesheet so a dark-theme page never flashes white. The nav's .site-nav-theme button toggles it; a "themechange" event lets canvases (roadmap, globe) repaint. {%- endcomment -%}
